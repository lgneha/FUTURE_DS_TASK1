# FUTURE_DS_TASK1
Future Interns – Data Science & Analytics Internship (Task 1)
This project showcases an interactive Ecommerce Sales Dashboard built using Power BI.
It provides insights into sales performance, profit distribution, customer trends, and category-wise revenue.
---
🚀 Dashboard Overview
✔ Key Metrics (KPI Cards)
Total Amount: 188K
Total Profit: 28K
Total Quantity: 43
AOV (Average Order Value): 4.37K
---
📈 Visuals Included in the Dashboard
🔹 Total Amount by Category (Bar Chart)
Displays sales distribution across Electronics, Furniture, Clothing & Accessories.
🔹 Total Amount by Year (Column Chart)
Shows sales trend for the year 2024.
🔹 Total Profit by State (Pie Chart)
Shows the contribution of each state (Maharashtra, Delhi, UP, MP, Rajasthan) to total profit.
🔹 Sum of Profit by Category (Bar Chart)
Visualizes profit generated from each category.
